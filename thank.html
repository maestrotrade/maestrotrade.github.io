Get started in MT4

  1. In MT4, select File → Open Data Folder. Put MAESTRO_WRAPPER_EA.mq4 in MQL4/Experts and the five .mqh files in MQL4/Include.
  2. Compile the wrapper in MetaEditor with F7, then refresh Expert Advisors in MT4’s Navigator.
  3. Attach one EA instance per Forex pair on an M1 chart. Keep AssetSelector at 1 for Forex. Review the inputs and test on a demo account before enabling live trading.
