01 • Before You Start

What you need.

You do not need to know programming. You need MetaTrader 4, your broker login, and the four supplied Maestro Trade executable EA files.

Required

  • MetaTrader 4 installed on a Windows PC or VPS
  • A broker account connected to MT4
  • MAESTRO_M1.ex4
  • MAESTRO_M5.ex4
  • MAESTRO_M15.ex4
  • MAESTRO_M30.ex4
  • Charts for the currency pairs you want the bots to monitor
  • Internet connection while the EAs are running

Simple rule to remember

M1 EA → M1 chart.

M5 EA → M5 chart.

M15 EA → M15 chart.

M30 EA → M30 chart.

If you want all four systems on the same pair, open four separate charts for that pair.

02 • Installation

Install the four EAs in MT4.

The supplied files are compiled .ex4 Expert Advisors, so normal installation does not require MetaEditor compilation.

1

Open MetaTrader 4

Log in to the trading account you want to use. For first testing, a demo account is strongly recommended.

2

Open the MT4 data folder

In MT4 click File → Open Data Folder.

3

Open the Experts folder

Open:

MQL4 → Experts
4

Copy all four Maestro Trade files

MAESTRO_M1.ex4 MAESTRO_M5.ex4 MAESTRO_M15.ex4 MAESTRO_M30.ex4

Place all four directly in MQL4 → Experts. Do not place them in Indicators or Scripts.

5

No compilation is required

The supplied files are already compiled .ex4 executables. You only need MetaEditor if you later receive source .mq4 files.

6

Return to MT4 and refresh

In Navigator, right-click Expert Advisors → Refresh. If the EAs still do not appear, close and reopen MT4.

03 • Charts

Prepare the currency-pair charts.

Open the currency pair you want to trade, for example EUR/USD. Use File → New Chart or open it from Market Watch.

M1: select M1 before attaching MAESTRO_M1.
M5: select M5 before attaching MAESTRO_M5.
M15: select M15 before attaching MAESTRO_M15.
M30: select M30 before attaching MAESTRO_M30.

Repeat this for every pair you intentionally want the system to trade. Your broker may use symbol suffixes such as EURUSD.a or EURUSD-ECN; always use the exact broker symbol.

08 • Running All Four

M1 + M5 + M15 + M30 on the same pair.

MT4 permits only one Expert Advisor on a single chart. To run all four Maestro engines on the same currency pair, open four separate charts.

Chart #1M1 + MAESTRO_M1
Chart #2M5 + MAESTRO_M5
Chart #3M15 + MAESTRO_M15
Chart #4M30 + MAESTRO_M30
MonitorExperts + Journal
Keep each EA on its intended timeframe. Do not casually alter Magic Numbers, duplicate-exposure controls, risk settings or other coordination/safety inputs unless you understand the effect across all running EAs.

10 • Activate

Attach each EA and turn on trading.

1

Find the EA

In Navigator → Expert Advisors, locate MAESTRO_M1, MAESTRO_M5, MAESTRO_M15 or MAESTRO_M30.

2

Attach it to the correct chart

M1 goes on M1; M5 on M5; M15 on M15; M30 on M30.

3

Review the Inputs tab

Review the supplied risk and operational settings before enabling automated trading. The actual Inputs shown by your EA build are authoritative.

4

Allow live trading

Enable Allow live trading only when you intentionally want that EA to place orders. Do not enable unnecessary DLL permissions.

5

Turn on MT4 AutoTrading

Click the AutoTrading button on the MT4 toolbar.

6

Confirm all active charts

Check the EA name/status on every M1, M5, M15 and M30 chart you configured.

11 • First-Run Check

Do not walk away yet.

Verify each EA independently before treating the installation as complete.

  • The correct broker account is logged in
  • MAESTRO_M1 is attached only to intended M1 charts
  • MAESTRO_M5 is attached only to intended M5 charts
  • MAESTRO_M15 is attached only to intended M15 charts
  • MAESTRO_M30 is attached only to intended M30 charts
  • AutoTrading is enabled when intended
  • The Experts/Journal tabs show no repeating errors
  • Configured risk is appropriate for the account
  • Calculated lot sizes look reasonable
  • Spread is not constantly blocking entries because of broker pricing
  • When a test trade occurs, protection/management behaves as expected
  • Telemetry/logging is being produced as expected
  • Zero trades can be a valid result while the EA waits for a qualifying setup

13 • Troubleshooting

Common beginner questions.

I copied the EAs but cannot see them in Navigator.

Confirm all four EX4 files are inside MQL4 → Experts. Right-click Expert Advisors → Refresh and restart MT4 if necessary.

Do I need to compile these files?

No. The supplied MAESTRO_M1.ex4, MAESTRO_M5.ex4, MAESTRO_M15.ex4 and MAESTRO_M30.ex4 files are already compiled MT4 Expert Advisors.

Can I put M1, M5, M15 and M30 on the same chart?

No. MT4 supports one Expert Advisor per chart. Open four copies of the pair and set each to the corresponding timeframe.

The EA is visible but does not trade.

Check AutoTrading, Allow live trading, the correct timeframe, market hours, spread, strategy qualification, exposure/risk controls and the Experts/Journal tabs. No trade can be the correct result.

Can I close MT4 after installing the bots?

No. Locally hosted EAs require the MT4 terminal to remain running and connected. Use an always-on PC or VPS for continuous operation.

Why keep the telemetry?

It allows you to study entry quality, favorable/adverse movement, market state, missed opportunities, exit behavior and whether later system changes actually improve economic performance.

Final Checklist

Four engines. One MAESTRO system.

Install the four supplied EX4 files, attach each to its matching timeframe, begin conservatively, monitor the first trades, and preserve telemetry so system changes can be evaluated over meaningful samples.
