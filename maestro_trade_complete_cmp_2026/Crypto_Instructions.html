01 • Package

Five files to start.

Keep these five supplied files together in one Windows folder.

MAESTRO_ENTRY.pyShared entry intelligence with centralized strategy, risk, learning, opportunity tracking and adaptive trade-management parameters.

02 • One-Time Computer Setup

Install Python and the required packages.

1

Install Python 3

Install a current Python 3 release for Windows. During installation, enable the option to add Python to PATH if offered.

2

Open Command Prompt

Press the Windows key, type cmd, and open Command Prompt.

3

Confirm Python works

python --version
4

Install the libraries used by all bots

python -m pip install ccxt pandas numpy python-dotenv

CCXT connects to NDAX; pandas and NumPy support market/indicator calculations; python-dotenv loads the shared .env.

03 • Folder Setup

Create one bot folder.

Create this folder in Windows:

C:\NDAX_BOT

Copy the five supplied files into it:

C:\NDAX_BOT\ .env MAESTRO_ENTRY.py Maestro_M1.py Maestro_M5.py Maestro_M15.py
Important: Make sure the scripts really end in .py and the configuration is exactly .env, not .env.txt. Do not rename MAESTRO_ENTRY.py unless you also change the imports in the bots.
04 • Shared Configuration

Use the supplied stable .env.

M1, M5 and M15 share the same account, arming, market-universe and output-path configuration.

NDAX credentials

Enter your own credentials locally:

NDAX_API_KEY=YOUR_API_KEY NDAX_API_SECRET=YOUR_API_SECRET NDAX_USER_ID=YOUR_USER_ID NDAX_ACCOUNT_ID=

The Account ID can normally remain blank if discovery succeeds. Never publish your completed .env.

Market universe

NDAX_SYMBOLS=BTC/CAD,ETH/CAD,XRP/CAD,SOL/CAD,ADA/CAD NDAX_AUTO_DISCOVER_CAD_MARKETS=true NDAX_AUTO_QUOTE=CAD

The system can also observe additional CAD markets for research when auto-discovery/full-market learning is enabled.

FIRST RUN — safe test setting

M15_PAPER_MODE=true M15_PAPER_START_BALANCE_CAD=500.00 LIVE_TRADING=false LIVE_ARM=

The supplied M1, M5 and M15 builds read this shared paper/live control.

Folders & learning state

M15_BASE_DIR=C:\NDAX_BOT MAESTRO_LOGS_DIR=C:\NDAX_BOT\Logs MAESTRO_JSON_DIR=C:\NDAX_BOT\Json MAESTRO_ENTRY_LEARNING_STATE_FILE=C:\NDAX_BOT\Json\maestro_entry_crypto_learning.json

11 • Live Trading

Only arm live mode intentionally.

Do not change this until paper testing, API authentication and telemetry behavior are verified. Live mode sends real orders and can lose real money.

Stop all three bots with Ctrl+C. To permit real orders, change:

M15_PAPER_MODE=false LIVE_TRADING=true LIVE_ARM=YES_REAL_ORDERS

Restart M1, M5 and M15 and verify the reported operating mode before allowing them to run.

Never distribute a customer package with your own filled-in API credentials. Each user enters credentials locally.

14 • Stop & Restart

How to shut the bots down safely.

To stop a bot, click its Command Prompt window and press:

Ctrl + C

Restart from C:\NDAX_BOT with the appropriate command:

python Maestro_M1.py python Maestro_M5.py python Maestro_M15.py
Critical live-mode note: before shutting down a live bot with an open position, inspect the actual NDAX position/order status and understand which protection remains exchange-side versus which management depends on the local Python process.
15 • Troubleshooting

Beginner questions.

'python' is not recognized.

Install Python 3 and make sure the PATH option is enabled, then reopen Command Prompt.

It says ModuleNotFoundError: MAESTRO_ENTRY.

Confirm MAESTRO_ENTRY.py is in the same C:\NDAX_BOT folder as Maestro_M1.py, Maestro_M5.py and Maestro_M15.py.

A Python package is missing.

Run python -m pip install ccxt pandas numpy python-dotenv.

The bot cannot find .env.

Confirm it is named exactly .env and is stored in C:\NDAX_BOT.

Why is the bot not trading?

A valid setup may not exist. Review the console plus opportunities, events and market-research telemetry before changing gates or risk controls.

Can I run M1, M5 and M15 together?

Yes. The supplied package is designed for the three bots to use the same .env and shared MAESTRO_ENTRY intelligence while running in separate Command Prompt windows.

Do these bots short crypto?

No. The supplied NDAX implementation is spot-long only.
