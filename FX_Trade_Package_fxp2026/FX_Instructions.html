01 • Before You Start

What you need.

You do not need to know programming. You only need MetaTrader 4, your broker login, and the supplied Maestro Trade EA files.

Required

  • MetaTrader 4 installed on a Windows PC or VPS
  • A broker account connected to MT4
  • The supplied M1 .mq4 or .ex4 EA
  • The supplied M5 .mq4 or .ex4 EA
  • Charts for the currency pairs you want the bots to monitor
  • Internet connection while the EAs are running

Simple rule to remember

M1 EA goes on an M1 chart.

M5 EA goes on an M5 chart.

If you want both systems on the same pair, open two separate charts for that pair: one M1 and one M5.

02 • Installation

Install the EA in MT4.

Follow these steps exactly. You normally do this only once for each EA file.

1

Open MetaTrader 4

Log in to the trading account you want to use. For first testing, a demo account is strongly recommended.

2

Open the MT4 data folder

In MT4 click File → Open Data Folder. A Windows folder will open.

3

Open the Experts folder

Open:

MQL4 → Experts
4

Copy the Maestro Trade EA files

Copy the supplied M1 and M5 .mq4/.ex4 files into the Experts folder. Do not place Expert Advisors in Indicators or Scripts.

5

If you received .mq4 source files, compile them

Open the file in MetaEditor and click Compile (or press F7 in many MT4 installations). A successful compile creates the executable .ex4 file. If an .ex4 is already supplied, compilation is normally unnecessary.

6

Return to MT4 and refresh

In the Navigator window, right-click Expert Advisors → Refresh. If the EAs still do not appear, close and reopen MT4.

03 • Charts

Prepare the currency-pair charts.

Open the currency pair you want to trade, for example EUR/USD. Use File → New Chart or open it from Market Watch.

For M1: select the M1 timeframe before attaching the M1 EA.
For M5: select the M5 timeframe before attaching the M5 EA.

Repeat this for every pair you intentionally want the system to trade. Your broker may use symbol suffixes such as EURUSD.a or EURUSD-ECN; always use the exact symbol shown by your broker.

04 • M1 Engine

How the M1 Fast Scalper works.

The M1 system looks for faster opportunities but does not simply buy or sell every one-minute move.

FAST ENGINE

M1 Fast Scalper

The current Maestro M1 design analyzes one-minute signals and can use the five-minute trend as a higher-timeframe confirmation.

  • Uses M1 for the trading signal
  • Can confirm direction with the M5 trend
  • Checks trend/momentum quality using EMA, RSI and ADX logic
  • Checks volatility and Bollinger-band width
  • Rejects oversized signal candles
  • Checks spread before entry
  • Calculates position size from the configured CAD risk cap
  • Creates stop-loss and take-profit automatically
  • Uses cooldown and daily safety limits

05 • M5 Engine

How the M5 Precision Trader works.

The M5 system is slower and more selective. It waits for a five-minute setup that passes its quality filters.

SELECTIVE ENGINE

M5 Precision Trader

The M5 engine is designed around continuation/momentum conditions rather than constant trading.

  • Analyzes completed M5 candles
  • Uses EMA 9/20 trend structure
  • Checks minimum EMA separation
  • Uses RSI quality zones
  • Uses ADX and directional +DI/-DI confirmation
  • Checks ATR, volatility and band width
  • Rejects poor spread conditions
  • Uses ATR-adaptive stop distance
  • Calculates lot size from the configured risk cap
  • Uses a defined reward-to-risk target

06 • Running Both

M1 + M5 on the same pair.

MT4 permits only one Expert Advisor on a single chart. Therefore, use two charts when running both Maestro engines on the same currency pair.

07 • Activate

Attach the EA and turn on trading.

1

Find the EA

In Navigator → Expert Advisors, find the Maestro M1 or M5 EA.

2

Attach it to the correct chart

Drag the EA onto the chart or double-click it. M1 goes on M1; M5 goes on M5.

3

Review the Inputs tab

Check RiskCAD and other settings. Do not increase risk simply because the EA is automated.

4

Allow live trading

In the EA properties, enable Allow live trading. Only enable DLL imports if a supplied version specifically requires them; do not enable unnecessary permissions.

5

Turn on MT4 AutoTrading

Click the AutoTrading button on the MT4 toolbar so automated trading is globally enabled.

6

Confirm the EA is active

Look at the upper-right corner of the chart. The EA name should be visible and MT4 should indicate that automated trading is enabled.

08 • First-Run Check

Do not walk away yet.

Before treating the setup as complete, verify these items.

  • The correct broker account is logged in
  • The M1 EA is attached only to M1 charts
  • The M5 EA is attached only to M5 charts
  • AutoTrading is enabled
  • The Experts/Journal tabs show no repeating errors
  • The configured RiskCAD is appropriate for your account
  • Lot sizes calculated by the EA look reasonable
  • Spread is not constantly causing rejection because of broker pricing
  • When a test trade occurs, SL and TP are present and correctly placed
  • You understand that a running EA can legitimately show zero trades while waiting for a valid setup

10 • Troubleshooting

Common beginner questions.

I copied the EA but cannot see it in Navigator.

Confirm it is inside MQL4 → Experts, not Indicators or Scripts. Right-click Expert Advisors → Refresh. If it is an MQ4 file, compile it in MetaEditor. Restart MT4 if necessary.

The EA is visible but it does not trade.

Check AutoTrading, Allow live trading, the correct timeframe, market hours, spread filters, strategy filters, and the Experts/Journal tabs. A valid bot can run normally without placing a trade if no setup qualifies.

Can I put M1 and M5 on the same chart?

No. MT4 supports one Expert Advisor per chart. Open two copies of the pair: one M1 chart for the M1 EA and one M5 chart for the M5 EA.

Can I close MT4 after installing the bots?

No. The terminal must remain running and connected for locally hosted EAs to operate. If you want 24/7 operation, use a suitable always-on PC or VPS.

Should I change RiskCAD?

Only intentionally. RiskCAD controls the intended monetary risk used in lot-size calculations. Start conservatively and verify actual broker execution before increasing it.

Does a 2:1 target mean I will make twice what I lose?

It means the strategy's target distance is designed around roughly two units of reward for one unit of defined risk in that M5 profile. Real fills, spread, slippage, gaps, stop constraints, and execution can make actual results different.
